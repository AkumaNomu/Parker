# Parker memory

Goal: make Parker a standout Windows utility people star, use daily, and want to help build.

## Product direction

Parker wins when it stays:
- hotkey-first;
- local-first;
- fast;
- privacy-safe;
- useful in one keystroke.

## Feature ideas with high upside

### 1. Screenshot-only mode
Copy region image directly to clipboard, no OCR. Fast, simple, broad use.

### 2. Local searchable history
Store recent captures, OCR text, QR results, and recordings with search. Big daily-use value.

### 3. Annotation and redaction
Crop, blur, highlight, arrow, box, and redact before copy or save. Strong portfolio feature.

### 4. Scroll capture
Long page / chat / document capture. Very visible, very shareable.

### 5. Active-window capture
Record current window, follow movement, auto-resize, no region drag each time.

### 6. Audio capture
Microphone and system audio profiles. Makes recording feel complete.

### 7. Pause / resume / discard recording
Basic recorder control. Improves trust and usability.

### 8. Local speech transcription
Turn completed recordings into searchable text. High wow factor.

### 9. Smarter actions
Auto-handle URL, email, file path, date, error stack, code block, equation, barcode.

### 10. Configurable hotkeys + tray UI
Users want control. This also helps adoption.

### 11. Post-capture rules
Per-app routing, custom commands, auto-open behavior, output templates.

### 12. Better recording engine
Per-monitor toast placement, Windows Graphics Capture / Desktop Duplication path, cleaner hardware acceleration.

## Contributor magnet features

- clear roadmap;
- small labeled issues;
- good first issue tags;
- benchmark samples;
- screenshot gifs in README;
- architecture docs;
- test fixtures for OCR / QR / recording edge cases;
- feature flags for optional subsystems;
- extension points for new detectors/actions.

## Best portfolio wins

If only a few big bets land first:
1. searchable history;
2. annotation/redaction;
3. scroll capture;
4. audio + transcription;
5. configurable hotkeys / automation.

Those give Parker stronger demo value, more repeat use, and more reasons for outside contributors to join.
